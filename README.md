# Seer Frights website

Static site for **seerfrights.com**.

## Structure

- `/` — home
- `/books/` — all books
- `/books/<title>/` — individual book pages
- `/about/` — series, author, and imprint
- `/404.html` — custom not-found page

## Design

The site was redesigned to use the same broad design language as Seer Worlds while keeping the Seer Frights identity:

- full-bleed illustrated hero
- transparent top navigation
- cream paper sections alternating with deep atmospheric sections
- modern card grids and cover strips
- responsive mobile menu
- original Seer Frights green accent palette
- high-resolution web-optimized hero artwork
- existing approved book covers retained unchanged

## Assets

- `images/hero-home.webp` — home hero
- `images/hero-sub.webp` — subpage and book-detail hero
- `images/about-scene.webp` — supporting about/home image
- `images/cover-*.jpg` — approved book covers

No build step is required.
